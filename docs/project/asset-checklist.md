# Asset Checklist

Short checklist for confirming required assets before launch.

Track anything the project needs but does not yet have. Remove rows once they are resolved.

## Outstanding Assets

| Asset  | Needed for | Source | Status |
| ------ | ---------- | ------ | ------ |
| _none_ |            |        |        |

## Status Values

- `Needed` — Not yet requested.
- `Requested` — Asked for, waiting on delivery.
- `Placeholder` — A stand-in is in place and must be replaced before launch.
- `Done` — Final asset is in the repository.

## Rules

- No `Placeholder` rows may remain at launch.
- Confirm licensing/usage rights for every third-party asset.
- Store delivered assets under `public/` following `docs/maintainability/assets-and-resources.md`.
